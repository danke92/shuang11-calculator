# 双11 减免计算器 · 视觉设计方案 v1

> 面向「大促省钱工具」的视觉语言：**可信的数字 + 电商大促的紧迫感 + 不刺眼的阅读体验**。
> 本方案是对现有 `index.html / styles.css` 的视觉升级规范，所有 token 与现有代码一一对应，可逐条落地。

---

## 1. 设计目标与原则

| 原则 | 含义 | 落地表现 |
| --- | --- | --- |
| **数字优先** | 用户来这只想看两个数字：最终到手价、省了多少 | 价格 42px/800 权重、紫色价格卡固定在右栏顶部，最居中的视觉层级 |
| **过程可信** | 优惠算法要能被复核，不能是黑箱 | 逐层明细显示「扣了多少 / 怎么算 / 还剩多少」，金额右对齐成列，方便扫读 |
| **大促氛围但不聒噪** | 要像双11，但不能满屏红黄闪 | 只在两处用高饱和：顶部栏品牌渐变、价格卡渐变；内容区保持白底 + 浅紫灰分隔 |
| **一屏一事** | 输入区、结果区、规则区互不干扰 | 双栏：左输入（可滚动填参数），右结果（sticky 吸附）；窄屏单栏重排 |
| **零依赖可离线** | 工具站在哪都能开 | 系统字体栈，不用 webfont；无外部 CDN；图标用内联 SVG |

## 2. 色彩系统

### 2.1 品牌与功能色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--accent` | `#7b2ff7` | 主品牌紫：选中标签、主按钮、链接、焦点环 |
| `--accent-strong` | `#5f16d6` | 紫色按钮 hover / 强调文字 |
| `--accent-deep` | `#5b21b6` | 需要在浅底上写紫字时使用（如 `#f4eeff` 底） |
| `--accent-soft` | `#f4eeff` | 紫色浅底：chip 背景、选中态浅底 |
| `--accent-line` | `#e4daff` | 紫色浅边框 |
| `--brand` | `#ff3b30` | 大促红：价格卡右端、折扣徽章、降价数字 |
| `--brand-2` | `#ff6b35` | 橙红过渡色（渐变中段、背景光晕） |
| `--brand-3` | `#ffb43b` | 点缀金：榜单名次、限时提示 |
| `--ok` | `#10b981` | 正向：达成门槛、最低价标记、保存成功 |
| `--warn` | `#f59e0b` | 提醒：差一点到门槛、资格待确认 |
| `--info` | `#3b82f6` | 信息：规则来源、外链提示 |

### 2.2 中性色阶

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#1b1035` | 标题、价格、主要数字（带紫调的近黑，避免死板） |
| `--ink-2` | `#4a4066` | 正文、表单值 |
| `--ink-3` | `#7c7391` | 辅助说明、字段 help 文案 |
| `--ink-4` | `#aea8c0` | 占位符、禁用文字（**仅装饰**，见 §8） |
| `--line` | `#e8e4f2` | 分隔线、卡片描边、输入框描边 |
| `--bg` | `#f6f4fb` | 页面底色（浅紫灰，比纯灰更贴合品牌） |
| `--card` | `#ffffff` | 卡片面 |

### 2.3 四平台识别色

每个平台给**两个**值：`-soft` 是浅底（配深色字），`-deep` 是深底（配白字）。选哪个取决于上面承载什么文字 —— 这是实测踩过的坑，见 §8。

| 平台 | 浅底 / 深色字 | 深底 / 白字 | 用于 |
| --- | --- | --- | --- |
| 淘宝 / 天猫 | `--tm #ff5000` + 白字（仅 ≥18px/700） | `--tm-deep #c23a00`（白字 5.4:1 ✅） | 选中标签、比价色条 |
| 京东 | `--jd #e1251b` + 白字 **4.7:1 ✅** | `--jd-deep #c8161d`（5.9:1） | 同上 |
| 拼多多 | `--pdd #e02e24` + 白字 **4.6:1 ✅** | `--pdd-deep #c01f18`（6.1:1） | 同上 |
| 抖音商城 | `--dy #00d4c8` 浅青 + **深青字 `#0b3a3a`（6.7:1 ✅）** | `--dy-deep #0f766e`（白字 5.5:1） | 同上 |

> 拼多多与京东的红色非常接近，**不要只靠颜色区分平台**：平台卡固定 `名称(粗) + 简称(灰) + 首字方块徽标`，颜色只做辅助。
> ⚠️ 抖音青底**绝不能配白字**（1.87:1，肉眼都糊）。
>
> **落地提示**：现有 `js/rules.js` 里天猫用的是 `#ff5000` + 白字，实测 3.28:1 未达 AA（≥18px/700 或 ≥14px/700 时算大字号，勉强可用）。落地时把标签文字设为 14px/700，或把天猫选中态换成 `#c23a00`。

### 2.4 关键渐变

```css
/* 顶部栏 */
background: linear-gradient(120deg, #2b0b4d 0%, #6c1a9c 42%, #ff3b30 100%);
/* 价格卡（紫色主导，右端透出红，避免大面积红造成压迫） */
background: linear-gradient(135deg, #2b0b4d, #6c1a9c 55%, #ff3b30);
/* 页面背景光晕 */
radial-gradient(1200px 500px at 12% -10%, rgba(255,107,53,.16), transparent 60%),
radial-gradient(1000px 460px at 92% 0%, rgba(123,47,247,.16), transparent 62%), var(--bg)
```

## 3. 字体与字号阶梯

字体栈（不加载 webfont，保证离线可用）：
`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", "Segoe UI", Roboto, sans-serif`

| Token | 字号 / 行高 / 字重 | 用途 |
| --- | --- | --- |
| `--fs-2xs` | 11.5px / 1.45 / 500 | 徽章、脚注、单位符号 |
| `--fs-xs` | 12.5px / 1.5 / 400 | help 文案、来源说明、提示列表 |
| `--fs-sm` | 13.5px / 1.55 / 500 | 明细行副文案、标签页 |
| `--fs-base` | 14px / 1.6 / 400 | 正文、输入框值 |
| `--fs-md` | 15px / 1.6 / 600 | 卡片小标题、比价平台名 |
| `--fs-lg` | 17px / 1.5 / 700 | 卡片标题 |
| `--fs-xl` | 20px / 1.4 / 700 | 区块标题、抽屉标题 |
| `--fs-price` | 42px / 1.1 / 800 | 到手价（`letter-spacing: -1px` 收紧，数字更整） |

**数字排版规则**
- 所有金额用 `font-variant-numeric: tabular-nums`，让明细里的金额**竖列对齐**（这是本工具最关键的排版细节）。
- 千分位统一 `toLocaleString`，保留两位小数：`¥2,149.15`。
- 优惠金额前缀 `-`，达成门槛用 `--ok`，未达成用 `--ink-3` + 「未生效」。

## 4. 间距、圆角、阴影

**间距（4 的倍数）**：`4 / 8 / 12 / 16 / 20 / 24 / 28 / 32`
- 卡片内边距：桌面 `20px 22px`，窄屏 `16px 14px`
- 卡片间距：桌面上下列间距 `18px`，双栏间 `22px`
- 表单字段组间距：`16px`；字段内 label → 控件 `6px`；控件 → help `6px`

**圆角**：`--r-sm 8px`（小控件）· `--r-md 12px`（输入框、按钮）· `--r-lg 16px`（卡片，= 现有 `--radius`）· `--r-pill 999px`（标签、徽章、chip）

**阴影（抬高 = 可交互 / 重要）**

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sh-sm` | `0 2px 8px rgba(49,24,96,.06)` | 明细行、小控件 |
| `--sh-md` | `0 10px 30px rgba(49,24,96,.08)` | 普通卡片（= 现有 `--shadow`） |
| `--sh-lg` | `0 18px 40px rgba(43,11,77,.30)` | 价格卡 |
| `--sh-accent` | `0 8px 20px rgba(123,47,247,.30)` | 主按钮 |

## 5. 核心组件规范

### 5.1 按钮

| 类型 | 常态 | hover | active | disabled |
| --- | --- | --- | --- | --- |
| 主按钮 `.btn-primary` | 紫底白字，`--sh-accent` | 底色 → `--accent-strong`，上移 1px | 回位，阴影收窄 | 透明 45%，`not-allowed` |
| 次按钮 `.btn-ghost` | 白底紫字，1px `--line` | 边框 → `--accent-line`，底色 `--accent-soft` | 同上 | 同上 |
| 场景 chip `.chip-btn` | `--accent-soft` 底 + `--accent-line` 边 | 反色：紫底白字 | 内阴影 | 同上 |
| 平台标签 `.tab` | 白底灰字胶囊 | 边框变平台色 | — | — |
| 平台标签（选中） | 平台色底 + 白字 + 平台色阴影 | — | — | — |

> 主按钮高度 46px（触控友好），宽度满行；标签/chip 高度 ≥ 32px。

### 5.2 表单控件
- 高度 42px，`border: 1px solid var(--line)`，圆角 `--r-md`；前缀单位（¥）用绝对定位的灰色小字，值左内边距 30px。
- **focus**：`border-color: var(--accent)` + `box-shadow: 0 0 0 3px rgba(123,47,247,.18)`（其他浏览器噪声一律去掉）。
- 数值输入右侧留出单位位（元 / 折 / 张），单位不用 placeholder 冒充。
- 开关用原生 `checkbox` 定制：44×26 胶囊，选中紫底白点，0.18s 过渡。

### 5.3 价格卡（结果区主角）
- 紫色渐变底 + 白字 + `--sh-lg`，圆角 `--r-lg`，内边距 22px。
- 结构：`标签(13px/0.78 透明) → 价格(42px/800) → 副信息(12.5px) → 进度条 → 三段统计`。
- 进度条 8px 高、圆角，实付段用 `rgba(255,255,255,.92)`，优惠段用 `rgba(255,255,255,.28)`，图例用 8px 圆点。
- 折扣徽章：`rgba(255,255,255,.16)` 底 + 1px 半透明白边 + 毛玻璃 `backdrop-filter: blur(6px)`，主数字 20px/800。

### 5.4 明细行（`.step` / `.brief-item`）
四列网格：`序号方块(28px) | 名称+算法说明 | 金额(右对齐,tabular-nums) | 剩余金额`。
- 未生效层：整行 `opacity: .55`，金额位显示「未生效」而非 `-0`。
- 门槛未达：金额位右侧追加 `--warn` 小标签「差 ¥140」，并在提示区给出「别硬凑」建议。
- 金额字重 700，与名称形成粗细对比；算法说明用 `--fs-xs` + `--ink-3`。

### 5.5 比价卡（四平台对比）
每行：`平台色首字方块(30px) + 平台名 + 标价/省额小字 + 到手价(右对齐,700)`；
最低价行加 `--ok` 描边 + 「最低」标签；卡片底部一行小字说明口径差异。
排序后第 1 行即为推荐，**不做额外的「推荐」结论**，避免替用户做决定。

### 5.6 徽章与状态

**颜色配对规则（实测过，别凭感觉）**：浅色底配深色字，深色底配白字，中间色（L 在 0.15–0.35 之间的 #ff5000 / #00d4c8 / #10b981）**两边都不好配**，一律当底色用、不承载小字。

| 组件 | 底色 | 文字色 | 对比度 |
| --- | --- | --- | --- |
| 折扣徽章（价格卡内） | `rgba(255,255,255,.16)` 半透明 | 白 | 随卡片渐变，实测 ≥7:1 ✅ |
| 「最低」标签 | `#d1fae5` | `#064e3b` | 8.6:1 ✅ |
| 门槛未达警示 | `#fef3c7` | `#92400e` | 6.4:1 ✅ |
| 优惠金额（白底） | 白 | `--brand #ff3b30` **仅 ≥16px/700** | 3.6:1 ⚠️ |
| 优惠金额（浅红底） | `#fff5f4` | `#c23a00` | 5.0:1 ✅ |
| 平台徽章（首字方块） | `--jd / --pdd` | 白 | 4.7 / 4.6:1 ✅ |
| 平台徽章（天猫） | `--tm-deep #c23a00` | 白 | 5.4:1 ✅ |
| 平台徽章（抖音） | `--dy #00d4c8` | `#0b3a3a` | 6.7:1 ✅ |

- 平台徽章：圆角 7px 方块，11.5px/700，双字以内。
- 折扣徽章：胶囊 + 毛玻璃，主数字 20px/800。
- 状态点：8px 圆点，`--ok / --warn / --ink-4` 三态，**必须配文字**（不单靠颜色）。

## 6. 布局与栅格

```
桌面 (≥941px)
┌──────────────────────────────────────────┐
│ 顶栏：品牌 + 倒计时 + 规则入口            │  全宽渐变
├──────────────────┬───────────────────────┤
│ 输入栏 (52%)      │ 结果栏 (48%, sticky)  │  wrap: max 1180px
│ ① 商品信息        │ 价格卡                │  双栏间距 22px
│ ② 可用优惠        │ 减免明细              │
│ ③ 比价            │ 省钱提示 / 比价结果    │
│                   │ 本平台规则摘要        │
└──────────────────┴───────────────────────┘
平板/手机 (≤940px)：单栏，结果卡镜像到输入区顶部，参数一改就看到价格
手机 (≤560px)：内边距 14px、价格 34px、比价行 66px 平台列、标签显示简称防截断
```

- 结果栏 `position: sticky; top: 74px`（顶栏高度 + 12px 呼吸位）。
- 断点只用两个：**940px**（双栏 → 单栏）、**560px**（紧凑档）。
- 抽屉（规则设置）：桌面右侧 520px 滑入；窄屏占满宽度，带遮罩。

## 7. 动效

| 场景 | 规范 |
| --- | --- |
| 通用过渡 | `.18s ease`（颜色、边框、阴影） |
| 按钮 hover | `translateY(-1px)` + 阴影加深；active 回位 |
| 标签切换 | 结果卡数字不做逐帧滚动（避免误导），仅底色 0.18s 淡入 |
| 抽屉 | 右侧 `translateX` 滑入 0.25s ease-out + 遮罩淡入 |
| 进度条 | `width` 过渡 0.3s ease-out |
| 无障碍 | `@media (prefers-reduced-motion: reduce)` 时全部降为 0.01s |

## 8. 无障碍与对比度（实测值）

用 WCAG 2.1 相对亮度公式逐个实算（不是估的）：

| 前景 / 背景 | 对比度 | 结论 | 允许用途 |
| --- | --- | --- | --- |
| `--ink` #1b1035 / 白 | **17.9:1** | AAA | 标题、价格、正文 |
| `--ink-2` #4a4066 / 白 | **9.5:1** | AAA | 正文、表单值 |
| `--ink-2` #4a4066 / `--accent-soft` #f4eeff | **8.4:1** | AAA | chip 内的正文 |
| 白 / `--accent` #7b2ff7 | **5.9:1** | AA | 主按钮、选中标签 |
| 白 / `--accent-strong` #5f16d6 | **8.2:1** | AAA | 按钮 hover 态 |
| `--accent` #7b2ff7 / `--accent-soft` #f4eeff | **5.2:1** | AA | 序号方块、chip 文字 |
| `--ink-3` #7c7391 / 白 | **4.45:1** | AA | ≥13px 辅助文案；不用于关键金额 |
| `--ink-3` #7c7391 / `--bg` #f6f4fb | **4.1:1** | AA | 同上 |
| 白 / `--jd` #e1251b | **4.7:1** | AA | 京东选中标签 |
| 白 / `--pdd` #e02e24 | **4.6:1** | AA | 拼多多选中标签 |
| 白 / `--tm-deep` #c23a00 | **5.4:1** | AA | 天猫选中标签（深色版） |
| `#0b3a3a` / `--dy` #00d4c8 | **6.7:1** | AA | 抖音选中标签（深青字） |
| 白 / `--brand` #ff3b30 | **3.55:1** | 大字号 | 仅 ≥16px/700 的金额或 ≥20px 徽章 |
| 白 / `--tm` #ff5000（现用于天猫标签） | **3.28:1** | 大字号 | 需 ≥14px/700；否则换 `#c23a00` |
| `--ink-4` #aea8c0 / 白 | **2.29:1** | ❌ 不可用 | 仅 placeholder / 禁用态 |
| 白 / `--ok` #10b981 | **2.54:1** | ❌ 不可用 | 绿色只做底/边框，文字用 `#064e3b` |
| 白 / `--dy` #00d4c8 | **1.87:1** | ❌ 不可用 | 抖音青底禁止配白字 |

**色相之外的三条硬规则**
1. 中性色（#ff5000 / #00d4c8 / #10b981 这类）**只当底色/边框**，其上的文字统一换成深色版（`#c23a00` / `#0b3a3a` / `#064e3b`）。
2. 所有可点击元素必须有 `:focus-visible` 可见焦点环（紫色 3px ring），禁止 `outline: none` 裸奔。
3. 状态不能只靠颜色：门槛未达配「差 ¥140」文字，最低价配「最低」标签。

## 10. 规范落地清单（建议顺序）

1. 把 §2–§4 的 token 全部补进 `:root`，现有变量名保持不变（`--accent/--brand/--ok/--line/--bg/--card/--ink*`），新增的只做补充，避免改动渲染逻辑。
2. 明细行金额加 `tabular-nums`（视觉收益最大的一条，`styles.css` 的 `.step` 区块）。
3. 统一 focus 环：给 `input/select/button/.tab/.chip-btn` 补 `:focus-visible`。
4. `--ink-4` 使用范围收敛到 placeholder / disabled。
5. **颜色配对抗锯齿化**：给 `--tm / --dy / --ok` 补深色版 token（`#c23a00 / #0b3a3a / #064e3b`），把「中性色底 + 白字」的组合改成「深色底 + 白字」或「浅色底 + 深色字」（见 §5.6、§8）。
6. `prefers-reduced-motion` 降级。
7. 平台色与深色字配对检查（抖音青底必须配 `#0b3a3a`）。
