2视觉基调

「可信的数字 + 大促氛围 + 长时间阅读不累」，高饱和色只出现在两处。

品牌紫 · 可交互

#7b2ff7 —— 主按钮、选中标签、焦点环。白字对比度 5.9:1。

大促红 · 价值感

#ff3b30 只用于 ≥16px/700 的优惠金额与折扣徽章；小字改用 #c23a00（5.0:1）。

中性紫灰 · 阅读

近黑标题 17.9:1，正文 9.5:1；浅紫灰底比纯灰更贴合品牌。

平台识别色 · 辅助

天猫 #ff5000（标签建议 #c23a00）/ 京东 #e1251b / 拼多多 #e02e24 / 抖音 #00d4c8（配深青字）。颜色不单独承载信息。

3五个关键设计决策

每一条都是为了这个工具的特定使用场景，而不是通用美化。

数字等宽对齐

金额统一 tabular-nums，明细里的「扣减 / 剩余」竖列对齐才好核对。

价格卡固定吸附

桌面 sticky 在右栏顶部；窄屏整卡镜像到输入区顶部，改参数立刻见价格。

过程可复核

每层写清「怎么算、达标没、还剩多少」，未生效层压暗但不隐藏。

不替用户下结论

比价只排序 + 标最低价，不写「推荐买 X」，避免误导消费决策。

状态不只靠颜色

门槛未达配「差 ¥140」文字，最低价配「最低」标签，色盲用户同样可读。

两档断点

940px 双栏转单栏，560px 紧凑档（内边距 14px、价格 34px）。

4落地顺序

改动都很小，按收益从高到低排。

  1. 把 token 全表补进 styles.css 的 :root（现有变量名保持不变）。
  2. 明细行金额加 font-variant-numeric: tabular-nums —— 单条改动，视觉收益最大。
  3. 给 input / select / button / .tab / .chip-btn 补统一 :focus-visible 焦点环。
  4. --ink-4 使用范围收敛到 placeholder 与禁用态。
  5. 加 prefers-reduced-motion: reduce 全局降级。
